# Student Grade Manager

A beginner-friendly Python program that manages student grades and calculates basic academic results.

## About the Project

I built this project while learning Python fundamentals. It helped me practice working with variables, input/output, conditional statements, loops, functions, and basic data handling.

## Features

* Add student information
* Enter and manage grades
* Calculate total and average marks
* Display student results
* Provide basic grade information

## Technologies Used

* Python

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Run the Python file:

```bash
python main.py
```
